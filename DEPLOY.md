# ПТН ПНХ — деплой у Telegram (крок за кроком)

Гра складається з двох частин:

| Частина | Що це | Де хоститься |
|---|---|---|
| `game/` | HTML5-гра (index.html + assets/) | Статичний хостинг, напр. **GitHub Pages** |
| `bot/`  | Node.js-сервер бота (тримає токен, викликає `setGameScore`) | Сервер, що постійно працює — напр. **Render.com** |

GitHub Pages не вміє запускати серверний код і не може безпечно зберігати токен бота, тому боту потрібен окремий хостинг. Гра ж — це просто статичні файли.

---

## Крок 1. Створити бота і гру через @BotFather

1. Напишіть [@BotFather](https://t.me/BotFather) → `/newbot`, дайте імʼя. Збережіть виданий **токен**.
2. `/mybots` → ваш бот → **Bot Settings → Inline Mode → Turn on** (гра працює через inline-механізм).
3. `/newgame`:
   - Оберіть бота.
   - Введіть назву гри, опис, завантажте зображення (та відео, опційно).
   - Введіть **short name** (латиницею, напр. `ptn_pnh`) — воно піде в `GAME_SHORT_NAME`.
   - URL гри BotFather запитає пізніше не тут — його ви вкажете в коді бота (крок 3).

---

## Крок 2. Викласти гру на GitHub Pages

```bash
# у папці game/ вже лежить index.html + assets/
cd game
git init
git add .
git commit -m "PTN PNH game"
git branch -M main
git remote add origin https://github.com/ВАШ_НІК/ptn-pnh-game.git
git push -u origin main
```

Потім у репозиторії: **Settings → Pages → Source: main branch, / (root)** → Save.
Через хвилину гра буде доступна за адресою типу:

```
https://ВАШ_НІК.github.io/ptn-pnh-game/index.html
```

Це і є ваш `GAME_URL`.

## Крок 3. Налаштувати й задеплоїти бота (Render.com, безкоштовно)

1. Заповніть `bot/.env.example` → перейменуйте на `.env` (для локального тесту) або внесіть ці ж значення як **Environment Variables** на Render:
   - `BOT_TOKEN` — токен з кроку 1
   - `GAME_SHORT_NAME` — short name з кроку 1
   - `GAME_URL` — посилання з кроку 2 (обовʼязково `.../index.html`)
   - `SIGNING_SECRET` — будь-який довгий випадковий рядок (наприклад, згенерований `openssl rand -hex 32`)
2. Створіть новий **Web Service** на [render.com](https://render.com), підключіть репозиторій із папкою `bot/`:
   - Build command: `npm install`
   - Start command: `npm start`
3. Після деплою Render дасть публічний URL, напр. `https://ptn-pnh-bot.onrender.com`.

### Прописати вебхук

Скажіть Telegram надсилати оновлення на ваш сервер (замініть значення):

```bash
curl "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://ptn-pnh-bot.onrender.com/webhook"
```

Успішна відповідь: `{"ok":true,"result":true,...}`.

## Крок 4. Прописати SCORE_ENDPOINT у грі

У `game/index.html` знайдіть рядок:

```js
const SCORE_ENDPOINT = 'https://YOUR-BACKEND-URL.example.com/api/score';
```

і замініть на реальний URL бота, наприклад:

```js
const SCORE_ENDPOINT = 'https://ptn-pnh-bot.onrender.com/api/score';
```

Закомітьте й запуште зміну — GitHub Pages оновиться автоматично.

## Крок 4.5. Відродження: поширення і винагороджувана реклама (опційно)

На екрані «Mission failed» тепер два способи відродитись із одним щитом, по черзі:

1. **Перший провал** — кнопка **«📤 Share with a friend · +1 shield»**. Відкриває діалог поширення Telegram (`t.me/share/url`) з посиланням на гру. Оскільки Telegram не дає callback «повідомлення реально надіслано», нагорода видається за стандартною евристикою «share-to-unlock»: коли гравець повертається у застосунок після відкриття вікна поширення (подія `visibilitychange`/`focus`).
2. **Другий провал** (в тому ж забігу) — кнопка **«▶ Watch ad · +1 shield»** через [Adsgram](https://adsgram.ai), рекламну мережу, спеціально створену під Telegram Mini Apps.
3. **Третій провал** — гра завершується остаточно, жодних кнопок відродження.

### Налаштування посилання поширення
У `game/index.html` знайдіть:
```js
const SHARE_URL = 'https://t.me/YOUR_BOT_USERNAME';
```
і вставте публічне посилання на вашого бота (те, що видав BotFather).

### Налаштування реклами (Adsgram)
Поки `AD_BLOCK_ID` в `game/index.html` не налаштований, кнопка автоматично показує **симуляцію реклами** (3-секундний таймер) — можна тестувати весь флоу без реального акаунту.

Щоб увімкнути справжню рекламу й монетизацію:
1. Зареєструйтесь на [adsgram.ai](https://adsgram.ai) як власник застосунку.
2. Створіть рекламний блок (Ad block) типу **Rewarded**, вкажіть посилання на вашого Telegram-бота.
3. Скопіюйте виданий **Block ID**.
4. У `game/index.html` знайдіть рядок:
   ```js
   const AD_BLOCK_ID = 'YOUR-ADSGRAM-BLOCK-ID';
   ```
   і вставте свій ID.
5. Задеплойте оновлений файл — симуляція автоматично зникне, і кнопка почне показувати реальну рекламу.

Кількість відроджень за забіг регулюється змінною `revivesUsed` у `game/index.html` (зараз максимум 2: поширення → реклама) — за потреби можна додати ще кроки в `gameOver()`.

## Крок 5. Перевірка

1. Напишіть своєму боту `/play` в особистих повідомленнях.
2. Прийде повідомлення-гра з кнопкою **Play**.
3. Натисніть — відкриється WebView з вашою грою (з `user_id`, `chat_id`, `message_id`, `sig` у параметрах URL).
4. Пройдіть раунд, програйте — рахунок автоматично піде на `/api/score` → бот викличе `setGameScore`.
5. Щоб побачити таблицю лідерів, викличте (наприклад, тимчасовим debug-запитом) `getGameHighScores` або просто пограйте кількома акаунтами — Telegram сам покаже "🏆 X гравців" під повідомленням гри.

## Нотатки з безпеки

- **Ніколи** не кладіть `BOT_TOKEN` у `game/index.html` чи будь-де на клієнті — тільки в `bot/.env` на сервері.
- Підпис (`sig`) у URL гри не дає підробити рахунок для чужого `user_id`/чату — `/api/score` перевіряє HMAC перед викликом `setGameScore`.
- `force: false` у `setGameScore` означає, що новий рахунок не перезапише вищий попередній — це стандартна поведінка для чесного лідерборду.

## Що можна покращити далі

- Додати `getGameHighScores` ендпоінт у бота, щоб показувати топ прямо в грі (не тільки в чаті Telegram).
- Розділити хвилі/рівні на іменовані (напр. "Хвиля 1: розвідка", "Хвиля 4: бронетехніка") для більшої драматургії.
- Додати мобільну вібрацію (`tg.HapticFeedback.impactOccurred`) при влучанні.
